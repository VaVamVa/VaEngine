### 크래시 수정 — AnimationRenderer 0x87A (두 원인)

**원인 #1 — `cmd.texture` 잔류 참조 (Phase 5 이후 미정리)**  
Phase 5에서 `RenderCommand.texture`가 제거됐으나 AnimationRenderer::Render()에 잔류 → 런타임 오류.

**원인 #2 — pre-bind 누락**  
`WorldAnimatedModel::cmd.material == nullptr` → 루프 진입 전 root1(b1), root3(t0)이 미바인딩 → GPU가 미초기화 descriptor 읽기 → D3D12 validation exception.

**수정 (루프 진입 전 pre-bind 패턴)**:
```cpp
material->UpdateBufferIfDirty();
cmdList->SetConstantBuffer(material->GetBuffer(), 1);  // root1 b1
defaultTexture->Bind(cmdList, 3);                       // root3 t0
IMaterial* boundMat = nullptr;
```
